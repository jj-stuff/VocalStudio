# README assets

Drop these in and the front page fills itself out:

| File | What |
|---|---|
| `icon.png` | App icon, 240×240 or larger, transparent background |
| `projects.png` | Projects list with a few projects in it |
| `studio.png` | The editor, mid-edit, with a clip selected |
| `effects.png` | The track panel sheet |
| `settings.png` | Settings, showing the Plus banner and Appearance |

Device frames aren't needed — plain screenshots at device resolution look fine
at the widths the README uses.
